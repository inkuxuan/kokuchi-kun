# コマンド一覧

すべてのコマンドはスラッシュコマンドです。チャット入力欄で `/` と入力すると利用可能なコマンドが表示されます。

## 一般コマンド

告知チャンネル以外でも使用できます。

| コマンド | 説明 |
|---------|------|
| `/ping` | Botがオンラインかどうかを確認します。現在のバージョンを返します。 |
| `/version` | 現在のBotバージョンを表示します。 |

## 管理者コマンド

**管理者ロールが必要です。** 告知チャンネル内でのみ使用できます。

| コマンド | 説明 |
|---------|------|
| `/list` | 現在スケジュールされているすべての告知をジョブIDと予定日時とともに一覧表示します。 |
| `/cancel <ジョブID>` | 指定したジョブIDの告知をキャンセルします。 |
| `/help` | 管理者コマンドの一覧を表示します。 |

## コマンドの補足

### `/list`

スケジュール済みの告知がある場合、以下の情報がEmbedで表示されます：

- ジョブID
- 投稿予定日時
- タイトル
- 内容（長い場合は省略）

告知がない場合は「予約されている告知はありません。」と表示されます。

### `/cancel <ジョブID>`

ジョブIDは予約完了Embedの「ジョブID」フィールドに記載されています。

キャンセルが成功すると「ジョブID abc123 の告知をキャンセルしました。」と表示されます。
