# はじめに

Kokuchi KunはDiscordからVRChatグループへの告知を自動スケジュールするBotです。

まずは[できること](./features)をご覧いただき、Botの機能をご確認ください。

## 導入方法

Kokuchi Kunを利用するには、以下の2つの方法があります。

### セルフホスティング

自分のサーバーにBotをデプロイして運用する方法です。ソースコードはオープンソースで公開されています。

- **GitHubリポジトリ：** [github.com/inkuxuan/kokuchi-kun](https://github.com/inkuxuan/kokuchi-kun)

READMEに記載されたセットアップ手順に沿って、環境構築・設定・デプロイを行ってください。

### マネージドサービス（アルファテスト中）

::: warning アルファテスト
マネージドサービスは現在**アルファテスト中**です。機能や仕様が予告なく変更される場合があります。
