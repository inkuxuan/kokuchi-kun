# Getting Started

Kokuchi Kun is a Discord bot that automates scheduling VRChat group announcements from Discord.

Check out [What Can It Do?](./features) to see the bot's features in action.

## How to Use Kokuchi Kun

There are two ways to get started with Kokuchi Kun.

### Self-hosting

Deploy the bot on your own server. The source code is open source.

- **GitHub repository:** [github.com/inkuxuan/kokuchi-kun](https://github.com/inkuxuan/kokuchi-kun)

Follow the setup instructions in the README to configure and deploy the bot.

### Managed Service (Alpha)

::: warning Alpha Test
The managed service is currently in **alpha testing**. Features and behavior may change without notice.
:::

If you prefer not to deploy the bot yourself, a managed service is being prepared. It is currently available as an alpha test. If you are interested, please reach out through either of the following:
